# Palm Tree Detection Using Deep Learning

## Overview

This project demonstrates the use of **deep learning and geospatial AI in ArcGIS Pro** to automatically detect palm trees from high-resolution RGB drone imagery. The workflow follows the ArcGIS Learn tutorial **“Detect objects with a deep learning pretrained model”** and uses a pretrained object detection model available through **ArcGIS Living Atlas**.

The project applies the **Detect Objects Using Deep Learning** geoprocessing tool to identify individual palm trees within aerial imagery and convert the model's predictions into spatial features. This provides an example of how deep learning can be integrated into GIS workflows to automate feature extraction from imagery that would otherwise require manual digitization.

## Workflow

The project involved:

* Preparing and working with high-resolution RGB drone imagery.
* Obtaining and applying a pretrained deep learning model from ArcGIS Living Atlas.
* Using **ArcGIS Pro's Detect Objects Using Deep Learning** tool for automated object detection.
* Configuring detection parameters, including the confidence threshold and non-maximum suppression.
* Generating spatial features representing detected palm trees.
* Reviewing the resulting detections to evaluate the model's performance and spatial distribution.
* Visualizing the detected objects alongside the original aerial imagery.

## Project Significance

This workflow demonstrates how deep learning can be used to automate the extraction of geographic features from remotely sensed imagery. Object detection models can reduce the time required for manual digitization and support applications such as vegetation inventories, agricultural monitoring, environmental assessment, and land-use analysis.

The project also provides practical experience with integrating **machine learning models into an ArcGIS-based spatial analysis workflow**, from imagery preparation through automated detection and spatial visualization.
